# Completion and handoff

- Check the agreed outcome and [risk-based evidence](testing.md#checks-by-change-risk). Refresh affected user and operator docs, [service continuation](services.md), and release notes as applicable. Use [product launch](product-launch.md) when refreshing public materials.
- Follow [delivery](github-release.md) for current-head checks and publication. Link the issue, PR, candidate revision, actual checks and, where applicable, the live revision and recovery instructions.
- Report current state and remaining dependencies using the [evidence contract](evidence.md). Keep local validation, merge, release publication, live verification and tenant visibility distinct.
- Validate skill behavior against [scenarios](scenarios.md), with no external side effects.
