# Explanatory illustrations

## Selection

- Use illustrations when they materially clarify the content. In a generated app, choose its illustration approach during discovery and record the decision with the branding guidance. Invoke Ian Xiaohei Illustrations only when that style is selected. In the canonical App Launchpad repository, follow its maintainer’s standing style preference.
- Read the actual `ian-xiaohei-illustrations` skill and mode-specific references. Template projects bundle it at `skills/ian-xiaohei-illustrations/SKILL.md`; otherwise discover the installed skill. If unavailable, record that dependency and continue independent work.
- Prefer the smallest useful set, one core concept per image; this preference overrides generic image quotas. Skip decorative repetition. Exact diagrams/charts, code examples and synthetic screenshots remain appropriate for precise information.
- Respect explicit product branding, language and image requirements; this preference does not replace logos/brand assets. The skill defaults to English labels, 16:9, white background, black hand-drawn lines, sparse annotation and Xiaohei participating in the action. Use original metaphors, not recycled example compositions.

## Generation and integration

- Choose plan_only/generate/edit/save from the request. Follow the skill's loading matrix and compact placement/meaning/spec table, generation tool, QA and safe-save rules; the spec is not another permission checkpoint.
- An unavailable image tool means blocked generation, not a fake asset or silently enabled API credentials/costs. Apply [safety](safety.md) to content sent to image tools.
- Save actual project outputs under `assets/<topic>-illustrations/` unless otherwise specified. Preserve originals; version sibling filenames rather than overwriting. Never leave project references pointing only into a tool cache.
- Verify aspect ratio, white background, core Xiaohei action, original metaphor, readable/minimal labels, no unwanted title, whitespace and saved path. Edit/regenerate failed checks.
- Add useful alt text and adjacent textual equivalents; inspect responsive readability, consuming theme/contrast, dimensions and loading behavior using the selected stack.
- Record placement, meaning/spec or prompt reference, saved path, QA and reviewed revision in the affected continuation. An image is explanatory content, not execution evidence.
- Preserve the bundled Ian MIT license/notice and attribution. Calibration examples are for occasional style reference, not production reuse. Upstream skill versions remain independent of template/app versions.
