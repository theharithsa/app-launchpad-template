# Product README structure

Copy the structure below into the generated repository's root README. Replace the bracketed notes with verified project details. Use screenshots from the running product with fictional data, and use the real URLs once the product page and demo are available.

```markdown
# [Product name]

[Who it serves, what they can do, and why it matters.]

[Open the app] · [Try the demo] · [Product page and video]

## Product walkthrough

[Show the main flow with a few images from site/media. Give each image useful alt text.]

## How it works

[Name the actual stack, main service boundaries, API, hosting, and runtime checks.]

## Run locally

[Give prerequisites, install and start commands, and the isolated test setup.]

## Contribute and report issues

[Contribution guide](CONTRIBUTING.md) · [Security policy](SECURITY.md)

Template version: **[source template version]** · [App Launchpad provenance](project.json)
```

Use the [product launch procedure](../.agents/skills/app-launchpad/references/product-launch.md) for screenshots, video, and publishing. See the FinBuddy release for a shipped example.
