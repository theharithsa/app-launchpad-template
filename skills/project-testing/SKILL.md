# Project Testing

Resolve affected services through the catalog. Read their test prerequisites and commands; record unknown commands as pending until the stack and suites exist. Use the [testing contract](../../.agents/skills/app-launchpad/references/testing.md).

Run focused tests for the change and integrated required checks for the current head. Exercise policy denial, failure, conflict/retry and real integrations as applicable. Keep unit, integration, browser and manual/device evidence distinct. Foundation checks validate metadata and scaffolding only.

Update each affected service's test paths/commands and continuation evidence with exact revision, run/tool, actual outcome and safe artifact links. Failed/skipped/not-run/blocked must remain visible. No fake suites, copied commands or fabricated passes.
