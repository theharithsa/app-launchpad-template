# Project Observability

Read each affected service's identity, signal ownership, entrypoints, approved environment map and telemetry tests. Apply the [observability contract](../../.agents/skills/app-launchpad/references/observability.md); use installed dt-obs where available without requiring it for this repository to be understandable.

Record approved RUM/consent, OTel initialization, logs/metrics/traces, durable business events and delivery health only for applicable components. Record service names, safe secret names, field allowlists, bounded dimensions, actual instrumentation/test paths and recovery procedures. Do not invent tenants or copy another app's identities.

Track source-confirmed issue/PR/review/check/merge/release/deployment facts and correlate actual deployed revision with runtime. Distinguish local tests, deployed configuration, ingest acceptance, tenant searchability and native RUM linkage in continuation evidence. Missing integration stays pending.
