# Illustrations

Use the [canonical selection and integration policy](../.agents/skills/app-launchpad/references/illustrations.md) and [Ian Xiaohei skill](../skills/ian-xiaohei-illustrations/SKILL.md).
The adapted package retains the local label 0.1.1; this is not a verified upstream
release tag. Its [MIT license](../skills/ian-xiaohei-illustrations/LICENSE),
[attribution notice](../skills/ian-xiaohei-illustrations/NOTICE.md) and
[pinned provenance](../skills/ian-xiaohei-illustrations/PROVENANCE.json) remain bundled.

The owner chose to remove the example PNGs because their redistribution license
has not been explicitly confirmed. The skill links to pinned upstream calibration
examples instead. Do not assume local `assets/examples/` files are present or
copy those images into a generated app. Generate original explanatory assets
when needed under the project's approved scope.
